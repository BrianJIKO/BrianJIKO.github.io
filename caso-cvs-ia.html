CONTEXTO DEL PROYECTO

Contexto del Proyecto

Este proyecto surge de la necesidad de optimizar el proceso de reclutamiento en empresas tecnológicas. Los equipos de recursos humanos reciben cientos de CVs diariamente, lo que hace imposible un análisis cuidadoso y consistente de cada candidato.

La plataforma fue desarrollada como solución integral para automatizar y mejorar este proceso, permitiendo a los reclutadores configurar criterios de evaluación personalizados y obtener análisis automáticos con métricas claras y accionables.

⚠️
PROBLEMA IDENTIFICADO

El Problema

Los reclutadores enfrentan sobrecarga de trabajo analizando currículums de forma manual, lo que resulta en evaluaciones inconsistentes y pérdida de candidatos potenciales.

  • Tiempo excesivo dedicado a filtrado manual de CVs
  • Falta de criterios consistentes entre evaluadores
  • Dificultad para identificar habilidades clave rápidamente
  • Pérdida de candidatos calificados por análisis superficial
🎯
OBJETIVO UX

Objetivo UX

Diseñar una interfaz intuitiva que permita a reclutadores configurar criterios de evaluación personalizados y obtener análisis automáticos de CVs con métricas claras y accionables.

  • Reducir tiempo de análisis de CVs en un 70%
  • Proporcionar métricas personalizables por rol
  • Crear un dashboard intuitivo y visualmente claro
  • Facilitar la toma de decisiones con datos
MI ROL Y RESPONSABILIDADES

Mi Rol y Responsabilidades

  • Investigación de usuarios con reclutadores
  • Arquitectura de información del dashboard
  • Diseño de flujos de usuario en Figma
  • Prototipado de alta fidelidad
  • Desarrollo front-end con React
  • Integración con API de IA
METODOLOGÍA

Proceso de Diseño

👥

Investigación

Entrevistas con 5 reclutadores para entender su flujo de trabajo actual y pain points principales.

📊

Arquitectura

Definición de estructura de información: dashboard, vista de candidatos, reportes.

✏️

Wireframes

Bocetos de baja fidelidad para validar flujos antes de invertir en diseño visual detallado.

🎨

Diseño UI

Sistema de diseño con componentes reutilizables, tipografía clara, paleta de colores profesional.

💻

Desarrollo
